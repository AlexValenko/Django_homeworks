# Домашняя работа 22

## Краткое описание

Данный проект представляет собой веб-сервис интернет-магазина.<br>
В настоящий момент разработка на начальном этапе.<br>
Проект выполнен в IDE PyCharm с использованием Poetry. Зависимости прописаны в toml-файле. В основе проекта фреймворк Django<br>

## Установка и использование
### Требования:
Python 3.14<br>
Poetry 2.3.2<br>

### Установка проекта
Клонируйте репозиторий<br>
git clone git@github.com:AlexValenko/Django_homeworks.git <br>
Установите poetry<br>
pip install poetry<br>
Установите зависимости<br>
poetry install <br>
Создайте и заполните файл /config/.env собственными данными по примеру файла /config/.env.example<br>

### Зависимости
В проекте используются следующие зависимости.<br>
*django (>=6.1,<7.0)* - предоставляет готовые решения для задач веб-сервиса<br>
*python-dotenv (>=1.2.2,<2.0.0)* - для работы с файлами переменного окружения <br>
Все необходимые настройки находятся в pyproject.toml.<br><br>
Для разработки используются инструменты:<br>
flake8 — проверка стиля кода<br>
black — автоформатирование кода<br>
isort — сортировка импортов<br>


## Основная функция
Основная функция задана в модуле manage.py в корне проекта. Для запуска сервера активируйте виртуальное окружение и введите в терминале команду<br>
python manage.py runserver<br>
После запуска сервера на локальном хосте можно открыть страницы:<br>
home (http://127.0.0.1:8000/home/)<br>
contacts (http://127.0.0.1:8000/contacts/)<br>
На странице contacts можно заполнить форму и отправить POST запрос. В результате появится сообщение об успешной отправке формы, а данные из формы будут выведены в консоль сервера.

### Описание функций

Проект разделен на логические блоки - приложения (в контексте фрэймворка Django).<br>

Настройки проекта и базовые пути описаны в модуле config.<br>
Весь реализованный на настоящий момент функционал проекта находится в приложении catalog.<br>
Модуль views отвечает за контроллеры, обрабатывающие запросы, модуль urls управляет маршрутизацией.<br>
